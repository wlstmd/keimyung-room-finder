# 🏫 계명대 빈 강의실 찾기

**지금 이 시간, 비어 있는 강의실을 지도에서 한눈에 확인하세요.**

계명대학교 **성서캠퍼스와 대명캠퍼스**의 강의실 정보를 기반으로
원하는 시간에 이용 가능한 빈 강의실을 빠르게 찾을 수 있습니다.

## ✨ 주요 기능

* 🗺️ **지도 기반 강의실 조회**

  * 건물별 빈 강의실 현황을 한눈에 확인
  * `빈 강의실 수 / 전체 강의실 수`로 표시

* ⏰ **시간별 조회**

  * 요일과 시간을 선택해 원하는 시점의 강의실 상태 확인
  * **「지금」 버튼**으로 현재 시간의 상태를 바로 조회

* 🏫 **건물·강의실 상세 정보**

  * 건물 선택 시 강의실별 사용 여부 확인
  * 사용 중인 강의실은 **수업명 · 교수님 · 수업 시간** 제공

* 📍 **위치 미확인 건물 지원**

  * 지도에 표시되지 않는 건물도 목록에서 선택하여 강의실 상태 확인

* 🏛️ **성서캠퍼스 · 대명캠퍼스 지원**

* 📊 **방문 통계**

  * 오늘 및 누적 페이지 조회 수 표시

## 🟢 강의실 상태

| 표시 | 상태       |
| -- | -------- |
| 🟢 | 대부분 비어있음 |
| 🟠 | 일부만 비어있음 |
| 🔴 | 전부 사용 중  |
| ⚪  | 정보 없음    |

## 📖 사용 방법

1. **캠퍼스와 요일**을 선택합니다.
2. **시간 슬라이더**를 움직여 원하는 시간을 선택합니다.
3. **「지금」 버튼**을 누르면 현재 시각 기준으로 조회할 수 있습니다.
4. 지도에서 건물을 선택하면 **강의실별 사용 상태**를 확인할 수 있습니다.

> 강의실 정보는 학교 공식 강의시간표를 기반으로 제공하며,
> 학기 변경 시 최신 시간표에 맞춰 업데이트됩니다.
