# 계명대 빈 강의실 찾기

- 지금 이 시간에 어느 강의실이 비어있는지 지도에서 바로 확인하는 서비스
- 성서캠퍼스와 대명캠퍼스를 모두 지원합니다.

## 사용법

1. **캠퍼스**와 **요일**을 고르고, 슬라이더로 **시간**을 옮기세요. "지금" 버튼을 누르면
   현재 시각 기준으로 바로 볼 수 있어요.
2. 지도의 말풍선은 건물이고, 숫자는 **비어있는 강의실 수 / 전체 강의실 수**예요.
   - 🟢 대부분 비어있음 · 🟠 일부만 비어있음 · 🔴 전부 사용 중 · ⚪ 정보 없음
3. 건물을 클릭하면 강의실별 상태가 떠요. 사용 중인 강의실은 수업명·교수님·시간까지
   같이 보여줘요.
4. 지도에 안 뜨는 건물은 "위치 미확인 건물" 목록에서 눌러도 강의실 상태를 볼 수 있어요.

강의실 정보는 학교 공식 강의시간표를 바탕으로 만들며, 학기가 바뀌면 최신 시간표로
업데이트합니다.
